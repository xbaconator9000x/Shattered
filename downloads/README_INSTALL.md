# Download the Shattered Essentials Android test patch

**The downloadable patch is `Shattered_v0.4_Johto_Gate_CORE_PATCH.zip` in this folder (23,886 bytes).** It is a binary ZIP file in the PRIVATE GitHub repository and can be downloaded without ChatGPT's Library or sandbox attachment service.

**Android installation:**

1. Use the original **Essentials FRLG V1.1.rar** game archive supplied previously from [Essentials FRLG v21.1 on Eevee Expo](https://eeveeexpo.com/resources/1797/). This small ZIP alone is **not a complete game**.
2. Extract the original RAR using ZArchiver to a fresh game folder containing `Game.exe`, `Game.ini`, `Data`, and `Graphics`.
3. Download the `Shattered_v0.4_Johto_Gate_CORE_PATCH.zip` file **from GitHub**, extract it into that same folder, and allow the `Data` and `Graphics` files to be merged/overwritten.
4. In JoiPlay with the RPG Maker Plugin, add the game's `Game.exe`; or in NaviaXP select the folder containing `Game.ini`.
5. Start **New Game**. Don't reuse an old FRLG save.

**Which prototype?** This is the **v0.4 original Pokémon Crystal-style League Reception Gate** build, not the separate planned Heart & Soul gate conversion. Johto south collapses, Aipom stand-in gives a key, and the east exit leads to Kanto Route 22 and then Viridian. Events are statically scripted but not yet verified on a phone. HUMAN is a Machop placeholder.
